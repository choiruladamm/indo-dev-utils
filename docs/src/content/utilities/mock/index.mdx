# Mock Generator

Generate structurally valid Indonesian test data for testing and development.

## Overview

The Mock module generates fake Indonesian data that passes the library's own validators:

- **NIK** — 16-digit Indonesian national ID
- **Phone** — Valid Indonesian mobile numbers with operator prefixes
- **NPWP** — Indonesian tax identification numbers
- **Plate** — Vehicle license plates (private)
- **Email** — Valid email addresses
- **Name** — Realistic Indonesian names

**Key feature:** All generators accept an optional `seed` for fully deterministic output. Same seed = same data, every time.

<Callout type="warning">
Generated data is **structurally valid but not real**. Do not use for fraudulent purposes.
</Callout>

### Features

- Zero external dependencies (pure algorithms)
- All generated values pass corresponding validators
- Deterministic output via optional seed
- Reuses constants from existing modules
- Works in Node.js and browser

## Quick Start

```typescript
import {
  generateNIK,
  generatePhone,
  generateNPWP,
  generatePlate,
  generateEmail,
  generateName,
  generateMockPerson,
  createMockFactory,
} from '@indodev/toolkit/mock';

// One-shot generation
const nik = generateNIK({ seed: 42 });        // Deterministic NIK
const phone = generatePhone({ seed: 42 });      // Deterministic phone
const person = generateMockPerson({ seed: 42 }); // Full mock person

// Factory for reproducible sequences
const factory = createMockFactory(12345);
const p1 = factory.generateMockPerson();
const p2 = factory.generateMockPerson();
// p1 and p2 are always the same for the same seed
```

## Determinism

All generator functions accept an optional `seed` parameter:

```typescript
// Same seed = same output
const nik1 = generateNIK({ seed: 42 });
const nik2 = generateNIK({ seed: 42 });
console.log(nik1 === nik2); // true — always identical
```

Without a seed, generators use `Date.now()` as the seed (non-deterministic).

```typescript
// Without seed — different each time
generateNIK();  // Different every call
generateNIK();  // Different every call
```

## API Reference

### generateNIK(options?)

Generates a structurally valid 16-digit Indonesian NIK.

```typescript
function generateNIK(options?: NIKMockOptions): string;
```

**Parameters:**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `options.gender` | `'M' \| 'F'` | Random | Gender for day encoding |
| `options.birthDate` | `Date` | Random 1960-2005 | Birth date to encode |
| `options.provinceCode` | `string` | Random | 2-digit province code |
| `options.seed` | `number` | `Date.now()` | For deterministic output |

**Returns:** 16-digit NIK string

**NIK Format:** `PP KK SS YY MM DD XXXX`
- PP: Province (11-96)
- KK: Regency (fixed 01)
- SS: Sub-district (fixed 01)
- YY: Year (00-30 = 2000s, 31-99 = 1900s)
- MM: Month (01-12)
- DD: Day (male: 01-31, female: 41-71 = day+40)
- XXXX: Serial (fixed 0001)

**Examples:**

```typescript
// Random NIK
generateNIK();  // '3212012903850001'

// Deterministic with seed
generateNIK({ seed: 42 });  // Always same output

// Specific gender and date
generateNIK({ gender: 'F', birthDate: new Date('1990-05-15'), seed: 1 });
// '3201019005550001'  (day 15 + 40 = 55 for female)

// Specific province
generateNIK({ provinceCode: '31', seed: 1 });
// '3101019005550001'  (31 = DKI Jakarta)
```

<Callout type="warning">
For female gender with custom birthDate, ensure day ≤ 28 to guarantee valid NIK encoding. Days > 28 may produce invalid day values.
</Callout>

### generatePhone(options?)

Generates a valid Indonesian mobile phone number.

```typescript
function generatePhone(options?: PhoneMockOptions): string;
```

**Parameters:**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `options.format` | `'national' \| 'international' \| 'e164'` | `'national'` | Output format |
| `options.operator` | `PhoneOperator` | Random | Mobile operator |
| `options.seed` | `number` | `Date.now()` | For deterministic output |

**Output Formats:**
- `national`: `08123456789` (11 digits starting with 0)
- `international` / `e164`: `+628123456789` (+62 prefix)

**Examples:**

```typescript
// Random phone in national format
generatePhone();  // '08123456789'

// International format
generatePhone({ format: 'international', seed: 1 });  // '+628123456789'

// Specific operator
generatePhone({ operator: 'Telkomsel', seed: 1 });  // '08123456789'
```

**Supported Operators:** Telkomsel, XL, Indosat, Axis, Tri, Smartfren

### generateBPJS(options?)

Generates a structurally valid Indonesian BPJS number for either scheme.

```typescript
function generateBPJS(options?: BPJSMockOptions): string;
```

**Parameters:**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `options.scheme` | `'kesehatan' \| 'ketenagakerjaan'` | `'kesehatan'` | Which BPJS scheme to produce |
| `options.seed` | `number` | `Date.now()` | For deterministic output |

**Returns:** numeric string — 13 digits for Kesehatan, 11 digits for Ketenagakerjaan. Passes `validateBPJS(scheme)`.

**Examples:**

```typescript
// Default: Kesehatan (13 digits)
generateBPJS();                          // e.g. '0001234567890'
generateBPJS({ seed: 42 });              // Deterministic

// Ketenagakerjaan (11 digits)
generateBPJS({ scheme: 'ketenagakerjaan', seed: 1 });  // e.g. '12345678901'
```

### generateVIN(options?)

Generates a valid 17-character Vehicle Identification Number with a correct check digit.

```typescript
function generateVIN(options?: VINMockOptions): string;
```

**Parameters:**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `options.manufacturerPrefix` | `string` | Random | Optional 3-char WMI segment (must be free of `I`, `O`, `Q`) |
| `options.seed` | `number` | `Date.now()` | For deterministic output |

**Returns:** 17-character string. Passes `validateVIN()`. Contains no `I`, `O`, or `Q`. Check digit at position 9 is correct per ISO 3779.

**Examples:**

```typescript
// Random valid VIN
generateVIN();                  // e.g. '1HBHA82L7ZB000001'
generateVIN({ seed: 42 });      // Deterministic

// Fixed manufacturer prefix
generateVIN({ manufacturerPrefix: 'JHM', seed: 1 });  // starts with 'JHM'
```

### generateMockPerson(options?)

Generates a complete mock person with consistent data across all fields.

```typescript
function generateMockPerson(options?: MockPersonOptions): MockPerson;
```

**Parameters:**

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `options.gender` | `'M' \| 'F'` | Random | Gender for all fields |
| `options.includeBPJS` | `boolean` | `false` | Attach a valid BPJS number to the person |
| `options.bpjsScheme` | `'kesehatan' \| 'ketenagakerjaan'` | `'kesehatan'` | Scheme when `includeBPJS` is true |
| `options.seed` | `number` | `Date.now()` | For deterministic output |

**Returns:** `MockPerson` object

```typescript
interface MockPerson {
  name: string;           // Full name
  gender: 'M' \| 'F';      // Consistent across fields
  birthDate: string;      // ISO 8601: 'YYYY-MM-DD'
  nik: string;            // Passes validateNIK()
  npwp: string;           // Passes validateNPWP()
  phone: string;          // Passes validatePhoneNumber()
  email: string;          // Passes validateEmail()
  plate: string;          // Passes validatePlate()
  bpjs?: string;          // Passes validateBPJS() — only present when includeBPJS: true
}
```

<Callout type="info">
The `bpjs` field is **absent by default** to preserve snapshot compatibility with v0.9.0. Set `includeBPJS: true` to attach a valid BPJS number to the person.

**Examples:**

```typescript
const person = generateMockPerson({ seed: 42 });
// {
//   name: 'Agus Santoso',
//   gender: 'M',
//   birthDate: '1985-03-15',
//   nik: '3201018503150001',
//   npwp: '012345678901234',
//   phone: '08123456789',
//   email: 'agus@gmail.com',
//   plate: 'B 1234 ABC'
// }

// Female with specific gender
const female = generateMockPerson({ gender: 'F', seed: 1 });
// Gender is consistent: NIK encodes female day, name uses female list
```


## Validation Guarantee

Every generator is designed so its output passes the corresponding validator:

| Generator | Validator |
|-----------|-----------|
| `generateNIK()` | `validateNIK()` from `@indodev/toolkit/nik` |
| `generatePhone()` | `validatePhoneNumber()` from `@indodev/toolkit/phone` |
| `generateNPWP()` | `validateNPWP()` from `@indodev/toolkit/npwp` |
| `generatePlate()` | `validatePlate()` from `@indodev/toolkit/plate` |
| `generateEmail()` | `validateEmail()` from `@indodev/toolkit/email-validator` |

```typescript
const nik = generateNIK({ seed: 42 });
validateNIK(nik);  // true — always passes

const phone = generatePhone({ seed: 42 });
validatePhoneNumber(phone);  // true — always passes
```
